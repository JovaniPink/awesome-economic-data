Prepared with material AI assistance for [issue #30](https://github.com/JovaniPink/awesome-economic-data/issues/30), suggested by the site's operator, @ChessShark1000. This is a maintainer review of a discovery interface; it does not independently validate every underlying statistic.

## Global Data Tracker

### Review scope and identity

| Field | Record |
| --- | --- |

The sampled measures were population, GDP and GDP per capita; no dataset export was exercised. |

### Measurement contract

| Field | Record |
| --- | --- |
| Measure and evidence type | An exploration layer over published annual World Bank indicators, which include statistical estimates. Moving population and GDP counters are separately modeled displays, not newly observed transactions or a live census. |
| Population and selection | Country and area coverage varies by indicator. The homepage displayed 20 measures across 217 countries and areas; that observed interface count is not a promise that every country has every year or series. The United States was the inspected country example. |
| Units and transformations | The source directory identifies population in people, GDP in current US dollars and GDP per capita in current US dollars per person. This review does not infer seasonal adjustment or a common price basis across other indicators. No additional analyst smoothing was applied. |
| Comparability and changes | Country definitions, reference years, statistical methods and missing observations can differ. The source directory supplies definitions and original-provider links. Cross-country or over-time comparability must be checked at the originating series; no historical definition-break audit was performed. |

### Timing and vintage

| Field | Record |
| --- | --- |
| Reference period | Annual reporting years attached to each measure; the inspected US page displayed 2025 for population, GDP and GDP per capita, and earlier years for other measures. These are reference labels, not retrieval dates. |
| Collection period | Unknown for the underlying series in this review. The original statistical publishers control collection periods; follow the measure-specific source before analysis. |
| Publication and vintage | The methodology identified saved release `wdi-2026-09-19-4d53fce7897c`. The US page labeled its data retrieval 2026-09-19. Neither label establishes the original publication date of every observation or proves an immutable public archive. |
| Retrieval date and observed coverage | The four website pages were inspected on 2026-11-25. Only rendered page content and the selected US measures were reviewed; first/last export periods were not tested. |
| Cadence and freshness limits | The publisher documents daily API checks while the site runs and replacement only after a complete release is saved. This is a publisher-stated check schedule, not daily observation frequency or independently observed nightly availability. |

### Access and artifact receipt

| Field | Record |
| --- | --- |
| Tested route and conditions | Public HTTPS pages were readable without supplying credentials, registering or paying. The review followed the methodology/source/country links; it did not connect an authenticated account. |
| Retrieved artifact | Decoded HTML page content only. No CSV, JSON export, API response or microdata was downloaded, parsed or counted for this review. |
| Snapshot identity | The displayed release identifier above was recorded. No immutable publisher snapshot, original file byte receipt or SHA-256 was captured; the inspected URLs are mutable. |
| Untested access | CSV/export controls, full published-history downloads, old shared releases, historical-vintage retrieval and the site's update mechanism. Visible controls and documentation do not establish successful exports or point-in-time reproducibility. |

### Terms and interpretation limits

| Field | Record |
| --- | --- |
| License and terms evidence | No blanket data or site-software reuse grant was established from the inspected provider pages. Footer image/software credits are separate from statistical-data rights. [World Bank terms](https://www.worldbank.org/ext/en/legal/terms-conditions), checked 2026-11-25, direct users to dataset-specific terms where applicable; a series-by-series rights review was not performed. |
| Reuse and attribution | This contribution links to the interface and supplies an original summary; it does not republish data or grant rights to underlying series. Users must preserve original-source attribution and verify the particular dataset's terms before redistribution or commercial reuse. |
| Interpretation limits | Latest in a saved release need not mean the latest provider release. Geographic views and animated counters do not establish real-time economic measurement. The site does not substitute for source methods, revision records or an admitted modeling dataset. |
